# 第四批实现任务 v0.1

状态：已完成（2026-08-21）  
对应阶段：P4 人工决策与合成

## 范围

本批实现追加式 Decision Log、事件重放、候选索引、区块完整性检查、冲突检测、可追溯合成、本地原子存储与 CLI。

本批不实现 UI、格式渲染、面试准备、真实第三方 Provider 或新权限。

## 任务

### 任务 1：决策事件与重放

- 验收：SELECT/REJECT/EDIT/UNDO 可稳定重放，事件序号和 ID 受校验。
- 验证：单元测试覆盖替换选择、拒绝恢复、编辑确认与撤销。

### 任务 2：候选完整性与合成

- 验收：仅合法同源候选可生效；最终区块具有 BASELINE/PROVIDER/USER_EDIT 追溯。
- 验证：集成测试覆盖哈希不一致、INSERT 冲突、MOVE 阻断与稳定 ID。

### 任务 3：本地存储与 CLI

- 验收：决策日志原子保存、可重载，合成结果默认不覆盖；命令可完成一次选择和合成。
- 验证：文件系统测试和 CLI 端到端测试通过。

## 完成门禁

- P4 新增行为全部有先失败后通过的测试。
- 完整测试、类型检查、构建和依赖审计通过。
- P4 完成后，P5 UI 只能调用本阶段公开 API，不自行实现第二套决策逻辑。
