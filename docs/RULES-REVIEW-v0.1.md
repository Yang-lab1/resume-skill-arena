## C. 默认工作流

确认以上规则后，用户实际看到的流程是：

1. 导入原始简历和 JD。
2. 系统锁定事实并默认推荐 3 个简历专家；用户可调整，但最多选择 5 个。
3. 多个专家从同一基线独立生成建议。
4. 系统过滤虚构、无证据和不安全建议。
5. 用户逐段比较、采用、编辑或融合。
6. 系统生成最终草稿并执行一页与版式检查。
7. 用户确认最终简历。
8. 系统再生成面试准备和修改审计报告。

## C.1 系统预审、统一确认、不中断主流程

- 用户主动选择或上传的简历、JD 和输出目录，视为本轮明确授权范围。
- Resume Studio 在首次运行前自动检查核心模块和已启用专家，生成一套最小权限方案；用户只需统一确认一次，不需要逐项理解或配置联网、Shell、域名、命令和目录。
- 默认确认页使用任务语言说明“为什么需要这些能力”和“会访问什么”，具体域名、命令、路径和风险放在“查看技术详情”中。
- 核心对比流程不依赖第三方 Skill 联网；用户可以直接上传简历并粘贴或上传 JD。
- 用户后来添加第三方 Skill 时，系统先完成来源、安全和权限预审，再展示一套推荐方案；默认操作只有“按推荐启用”或“跳过”，高级设置才允许逐项调整。
- 用户拒绝第三方权限时，只将该专家标记为跳过或降级，不阻断其他专家、比较、编辑和导出。
- 宿主应用自身的系统级安全确认仍由 Codex、WorkBuddy 或操作系统控制，Resume Studio 不绕过宿主安全机制。
